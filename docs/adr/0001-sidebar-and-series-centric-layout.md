# 0001: Collapsible Sidebar and Series-Centric Layout

We decided to replace the top-tab navigation (Dashboard / Library) with a collapsible left sidebar, a series-centric library with slide-over chapter drawers, and a global job modal with a floating progress dock. This maximizes vertical canvas area for reading and covers, keeps active downloads visible from anywhere without navigating away, and organizes multi-chapter manga cleanly by series.
